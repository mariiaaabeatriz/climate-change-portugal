# climate-change-portugal
This project analyses temperature trends in Portugal between 1990 and 2025 using official climate datasets. The objective is to investigate evidence of climate change through temporal and spatial analyses using Python and GIS tools.

The analysis uses the ERA5 2 m air temperature variable, which represents the air temperature measured two metres above the land surface. This is the standard variable used in climatological studies to assess long-term temperature trends and climate change.
